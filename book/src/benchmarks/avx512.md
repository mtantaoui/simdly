## Parallel

`ParSliceExt` and `ParSliceMath` (feature `rayon`) on every thread of the
machine, from the `par` and `rayon` results of the same groups; see
[Parallelism](../parallel.md). Up to the threshold (262 144 elements for
math, 524 288 for arithmetic and comparisons) `par_` runs on one thread,
so "over one thread" is about 1× there.
